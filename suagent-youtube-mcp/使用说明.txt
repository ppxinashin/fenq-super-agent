===============================================
  SuAgent-YouTube-MCP 后台运行脚本 - 使用说明
===============================================

📦 已创建的文件：
---------------------------------------------
  环境管理脚本：
    - setup_env.sh      环境初始化（创建conda环境）
    - check_env.sh      环境检查
  
  服务管理脚本：
    - start.sh          启动服务（后台运行）
    - stop.sh           停止服务
    - restart.sh        重启服务
    - status.sh         查看状态
  
  日志管理脚本：
    - rotate_logs.sh    日志轮转
  
  文档：
    - README_SCRIPTS.md 快速参考手册
    - 使用说明.txt      本文件

===============================================
  🚀 首次使用（完整流程）
===============================================

1. 初始化环境
   $ ./setup_env.sh
   
   说明：
   - 创建名为 suagent-youtube-mcp 的 conda 环境
   - 使用 Python 3.13
   - 自动安装 requirements.txt 中的所有依赖
   - 仅需运行一次

2. 检查环境
   $ ./check_env.sh
   
   说明：
   - 验证 conda 环境是否正确创建
   - 检查 Python 版本
   - 检查关键依赖包是否安装

3. 启动服务
   $ ./start.sh
   
   说明：
   - 自动激活 conda 环境
   - 后台运行 main.py
   - 日志输出到 logs/suagent-youtube-mcp.log

4. 查看状态
   $ ./status.sh
   
   显示：
   - 运行状态（运行中/已停止）
   - 进程 PID
   - 运行时长
   - 内存使用
   - 最近10行日志

5. 实时查看日志
   $ tail -f logs/suagent-youtube-mcp.log

===============================================
  📝 日常使用
===============================================

启动服务：
  $ ./start.sh

停止服务：
  $ ./stop.sh

重启服务：
  $ ./restart.sh

查看状态：
  $ ./status.sh

查看日志：
  $ tail -f logs/suagent-youtube-mcp.log        # 实时跟踪
  $ tail -n 100 logs/suagent-youtube-mcp.log    # 最近100行
  $ grep ERROR logs/suagent-youtube-mcp.log     # 搜索错误

轮转日志：
  $ ./rotate_logs.sh

===============================================
  🔧 高级操作
===============================================

手动激活环境：
  $ conda activate suagent-youtube-mcp

更新依赖：
  $ conda activate suagent-youtube-mcp
  $ pip install -r requirements.txt

重建环境：
  $ ./setup_env.sh
  （脚本会询问是否删除现有环境）

查看所有conda环境：
  $ conda env list

删除环境：
  $ conda deactivate
  $ conda env remove -n suagent-youtube-mcp

===============================================
  📊 日志说明
===============================================

日志位置：
  - 主日志：logs/suagent-youtube-mcp.log
  - PID文件：logs/suagent-youtube-mcp.pid
  - 备份：logs/suagent-youtube-mcp.log.*.gz

日志特点：
  - 所有输出（stdout和stderr）集中在一个文件
  - 自动添加时间戳
  - 自动轮转（超过100MB）
  - 保留最近10个备份

===============================================
  🐛 故障排查
===============================================

问题1：conda 命令未找到
  解决：先安装 Miniconda 或 Anaconda
  参考：https://docs.conda.io/en/latest/miniconda.html

问题2：环境不存在
  检查：$ conda env list
  解决：$ ./setup_env.sh

问题3：服务启动失败
  步骤：
    1. $ ./check_env.sh        # 检查环境
    2. $ cat logs/suagent-youtube-mcp.log  # 查看错误日志
    3. $ conda activate suagent-youtube-mcp
    4. $ python main.py        # 手动测试

问题4：依赖包缺失
  解决：
    $ conda activate suagent-youtube-mcp
    $ pip install -r requirements.txt

问题5：PID文件错误
  解决：
    $ ./status.sh              # 先检查状态
    $ rm -f logs/suagent-youtube-mcp.pid  # 手动清理
    $ ./start.sh               # 重新启动

===============================================
  ⚙️ 自动启动（可选）
===============================================

方法1: 使用 crontab
  $ crontab -e
  添加：@reboot cd /home/ubuntu/fenq-super-agent/suagent-youtube-mcp && ./start.sh

方法2: 使用 systemd
  创建服务文件 /etc/systemd/system/suagent-youtube-mcp.service
