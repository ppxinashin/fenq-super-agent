# 工具调用限制问题修复说明

## 问题描述

在使用 `ToolCallLimitMiddleware` 限制工具调用次数时，即使设置了 `run_limit=5`，agent 仍然会达到递归限制（默认25次），而不是在5次工具调用后停止。

## 根本原因

### 1. 配置传递问题

`recursion_limit` 被错误地放在了 `configurable` 字典中，正确的做法是将其放在配置的根级别。

### 2. 递归限制 vs 工具调用限制

需要理解两个不同的限制概念：

#### recursion_limit（递归限制）
- **含义**: 限制整个 agent 的最大循环次数
- **默认值**: 25
- **配置位置**: config 根级别

#### run_limit（工具调用限制）
- **含义**: 限制工具被实际调用的次数
- **配置位置**: ToolCallLimitMiddleware 的参数
- **行为**: 达到限制时跳到 "end" 节点或抛出错误

## 解决方案

### 1. 正确的配置方式

```python
config = {
    "configurable": {"thread_id": self.chatId},
    "recursion_limit": 100  # 在根级别
}
```

### 2. 合理配置限制参数

```python
agent = MyAgent(
    middlewares=[
        ToolCallLimitMiddleware(
            run_limit=5,
            exit_behavior="end"
        )
    ]
)

agent.invoke(
    {"messages": [HumanMessage(content="...")]}, 
    cfg={"recursion_limit": 100}
)
```

## 使用建议

### 1. 选择合适的限制值

- **recursion_limit**: 通常设置为 50-100
- **run_limit**: 
  - 搜索任务：5-10 次
  - 简单任务：3-5 次
  - 复杂任务：10-20 次

### 2. 选择合适的退出行为

```python
# 优雅结束
ToolCallLimitMiddleware(run_limit=5, exit_behavior="end")

# 抛出异常
ToolCallLimitMiddleware(run_limit=5, exit_behavior="error")
```

### 3. 针对特定工具的限制

```python
# 全局限制
global_limiter = ToolCallLimitMiddleware(run_limit=10)

# 只限制搜索工具
search_limiter = ToolCallLimitMiddleware(
    tool_name="duckduckgo_results_json",
    run_limit=3
)
```

- ✅ 修复了配置传递问题
- ✅ 提供了正确的配置方式
- ✅ 解释了递归限制和工具调用限制的区别
